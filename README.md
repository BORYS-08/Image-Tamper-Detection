# 🔍 Image Tamper Detection

A Python-based image tampering detection system that identifies manipulated images using image processing techniques and generates comparison reports.

---

## 📌 Project Overview

This project detects image tampering by comparing an original image with a suspected modified image. It highlights differences, generates visual outputs, and exports the analysis results.

---

## ✨ Features

- Detects image tampering
- Generates comparison images
- Highlights modified regions
- Exports results to Excel
- Saves output images automatically

---

## 🛠 Technologies Used

- Python
- OpenCV
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-image
